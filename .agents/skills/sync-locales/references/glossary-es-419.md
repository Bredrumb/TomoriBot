# Glossary for es-419 (Neutral Latin American Spanish)

## Localization Rules
* Address a single user informally with "tú" (never "vos" or "usted").
* Address groups with "ustedes" (never "vosotros").
* Use neutral Latin American Spanish understood from Mexico to Argentina.
* Never use Spain-only vocabulary such as "ordenador", "móvil", "vale", or "coger".
* Tomori and persona names are proper names and must remain unchanged.
* Capitalization follows standard Spanish rules; do not capitalize every word in a title unless it is a proper noun.

## Terminology Glossary

| English Term | Chosen Translation | Usage Note |
|---|---|---|
| alter | alter | A secondary persona. Masculine noun, plural alters (el alter, los alters). |
| API key | clave de API | The credential used to authenticate with an AI provider. |
| BYOK | BYOK | Acronym for Bring Your Own Key. Can be expanded to "Trae tu propia clave" if needed. |
| capability | capacidad | Refers to the features and tools the bot or model can use. |

| channel override | excepción de canal | Settings that replace the server default in one channel. Plural: excepciones de canal. |
| cooldown | enfriamiento | The wait before the bot can be triggered again. Not tiempo de espera, which reads as a timeout. |
| deliberate trigger mode | modo de activación deliberada | Controls when the bot replies without being addressed directly. Deliberate tool mode: modo de herramientas deliberado. |
| embed | embed | Standard Discord terminology for rich embedded messages. |
| humanizer | humanizador | The feature or setting that makes text sound less robotic. |
| lineage | linaje | Refers to the origin or version history of a character or preset. |
| main persona | persona principal | The primary character responding in the server. |
| memory | memoria | The bot's ability to recall past interactions or facts. |
| model | modelo | The underlying AI model, like Gemini or GPT. |
| notice | aviso | A visible message showing what the bot is doing behind the scenes. |
| panel | panel | The interactive configuration interface sent by the bot. |
| personal memory | memoria personal | Memories specific to a single user. |
| personal override | ajuste personal | A user's own setting that replaces a server default. Plural: ajustes personales. |
| persona | persona | The character the bot plays. Feminine noun (la persona, las personas). |
| persona override | excepción de persona | Settings for one persona that replace the server default. Plural: excepciones de persona. The verb "override" is reemplazar. |

| provider | proveedor | The service hosting the AI model. |

| reminder | recordatorio | A scheduled task or message to be sent in the future. |
| self-hosting | autoalojamiento | The act of running the bot on your own hardware. |
| server | servidor | A Discord server (guild). |
| server default | valor predeterminado del servidor | The baseline settings applied to the whole server. |
| server memory | memoria del servidor | Memories shared across the entire server. |
| short-term memory | memoria a corto plazo | Recent chat context retained for the current conversation. |
| slash command | comando de barra | Commands initiated by typing a slash in Discord. |
| sprite | sprite | Images representing the persona's different expressions. |
| sticker | sticker | Discord's visual communication feature. |
| teach | enseñar | The action of giving the bot new memories or instructions. |
| thread | hilo | A Discord thread inside a channel. |
| tool | herramienta | Agentic capabilities the bot can use. |
| trigger word | palabra de activación | A word that makes the bot reply. Trigger (noun) is activación; trigger (verb) is activar. |
| webhook | webhook | Standard Discord term for webhooks used to send messages. |

## Rejected renderings

* Override: the draft used anulación, which reads as cancellation. Channel and persona overrides are
  excepciones; a user's personal override is ajuste personal.
* Preset: ajuste preestablecido replaced by preajuste to fit Discord's 100 character menu limits.
* Cooldown: tiempo de espera replaced by enfriamiento, because tiempo de espera means timeout.
* Trigger word: palabra desencadenante replaced by palabra de activación, matching modo de activación.
