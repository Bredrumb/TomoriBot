# TomoriBot pt-BR Terminology Glossary

## General Guidelines

- **Register:** Friendly, clear, and approachable. Match the casual yet functional tone of Discord users.
- **Addressing the User:** Use "você" (second person singular, using third-person verbs). Avoid overly formal addressing (e.g., "o(a) senhor(a)"). Try to write sentences in a gender-neutral way regarding the user where possible to be inclusive.
- **Capitalization:** Use sentence case for most strings per standard Portuguese rules. UI elements (buttons, menus) can use title case if necessary to match Discord's native UI feel.
- **Proper Names:** "Tomori" and all persona names are proper names and should never be translated or altered.
- **Gender & Pluralization:** 
  - *Persona* is a feminine noun in Portuguese ("a persona", "as personas"). 
  - *Alter* is generally treated as a masculine noun ("o alter", "os alters") in DID/Plural communities in Brazil.
  - *Tomori* is treated as female/feminine when pronoun usage is unavoidable.

## Terminology Table

| English Term | pt-BR Translation | Usage Note |
|--------------|-------------------|------------|
| persona | persona (f) | The core identity or character. Kept as "persona", a feminine noun. |
| alter | alter (m) | Additional personas running alongside the main one. Treated as a masculine noun. |
| main persona | persona principal (f) | The primary persona configuration for a server. |
| server default | padrão do servidor (m) | Refers to settings or models applied to the whole server by default. |
| personal override | substituição pessoal (f) | Used when a user provides their own API key/settings that override the server's. |
| provider | provedor (m) | The AI backend service (e.g., OpenAI, OpenRouter, NovelAI). |
| model | modelo (m) | The specific LLM or AI model being used. |
| memory | memória (f) | General term for the bot's stored context or facts. |
| server memory | memória do servidor (f) | Facts and contexts related to the Discord server itself. |
| personal memory | memória pessoal (f) | Facts the bot remembers specifically about a user across servers. |
| short-term memory | memória de curto prazo (f) | Often abbreviated as STM in English; can use "MCP" or keep "STM" if space is limited, but "memória de curto prazo" in full text. |
| teach | ensinar (verb) | The action of giving the bot new facts to remember. |
| trigger word | palavra-gatilho (f) | The specific words that cause the bot to respond. Plural: "palavras-gatilho". |
| sticker | figurinha (f) | Standard Discord pt-BR localization for stickers. |
| sprite | sprite (m) | Emotion avatars/images. Kept as the English loanword as it's common in gaming/visual novel contexts. |
| humanizer | humanizador (m) | The setting that controls how human-like or strict the bot's responses are. |
| capability | capacidade (f) | A bot feature or permission (e.g., image generation, tool use). |
| tool | ferramenta (f) | Agentic functions the bot can call (e.g., search, reminders). |
| cooldown | tempo de recarga (m) | Standard gaming localization for a waiting period before an action can be used again. |
| self-hosting | hospedagem própria (f) | Can also use "self-hosting" as a loanword, but "hospedagem própria" is clearer for documentation. |
| BYOK | BYOK | "Bring Your Own Key". Keep as BYOK but can be explained as "Traga Sua Própria Chave". |
| webhook | webhook (m) | Discord technical term, kept as-is. |
| preset | predefinição (f) | A saved configuration of a personality or prompt. |
| lineage | linhagem (f) | The history or derivation path of a character or preset. |
