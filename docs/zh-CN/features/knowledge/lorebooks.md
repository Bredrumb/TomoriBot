世界书是用于角色扮演世界、人物以及反复出现的故事细节的高级记忆。日常对话请使用「记忆」。当世界书条目的关键词出现在最近的消息中时，它们会回忆起你所写下的细节。

在 `/memories` > `世界书` 中管理世界书。每位成员都可以查看当前范围内的条目；只有拥有 `管理服务器` 权限的成员才能添加、编辑、导入、导出或删除条目。

## 全服务器与人格世界书

世界书拥有两个作用域：

- **全服务器**世界书适用于服务器中的每个人格。请先选择一本世界书，然后在其中选择条目。
- **人格**条目属于某一个人格记忆谱系。在人格被删除并重新导入后，这些条目仍然继续生效。

使用页面顶部的 `全服务器` 和 `人格` 按钮来切换作用域。人格列表会将共用同一记忆谱系的人格归为一组，因为它们共用同一本书。频道限制与全服务器/人格作用域是两项独立的控制：作用域决定了谁拥有该条目，而频道则决定了它可以在何处出现。

## 编写条目

为每个条目设置标题、关键词以及最多 4,000 个字符的内容。关键词是以逗号分隔的词语或短语。匹配时会忽略大小写以及全角/半角差异。

对于无需关键词匹配即可生效的背景事实，关键词可保持留空。再次添加关键词即可恢复关键词匹配。新条目默认使用人格之后的插入位置；导入的条目保持其原本的位置。SillyTavern 预设集的世界设定槽位控制人格之前与人格之后两组内容的出现位置。

## 条目何时生效

已启用的条目必须匹配关键词才能生效，除非其关键词留空。作用域与频道限制对没有关键词的条目仍然有效。

`生效规则` 控制次要关键词、搜索最近消息的数量（1 到 100 条）、触发几率以及插入顺序。次要关键词可以要求匹配任意关键词（OR）、匹配所有关键词（AND）、不匹配任何关键词（NOR）或未全部匹配（NAND）。插入顺序数值越小，出现得越靠前。

触发几率从 0% 到 100%。设为 0 则不生效，包括没有关键词的条目。导入文件中缺失或为 null 的概率默认为 100%；显式设置的 0% 保持为 0%。`已关闭` 的条目会保持保存状态，不会进入提示词。

关键词匹配为精确字面匹配。类似 `/a+/` 这样正则表达式格式的关键词会按原文保留，不会作为正则表达式执行。

## 进入提示词的内容

生效的条目会按插入顺序，在每个插入位置作为一个 `World Info` 区块发送。两个区块共用 8,000 个字符的上限；超出上限的条目会被跳过，以便后续条目仍能容纳。

内容中可以使用 `{{user}}`、`{{char}}` 和 `{{bot}}`。TomoriBot 会将它们替换为当前的实际名称。其他 `{{...}}` 宏与条件块保持原样。

## 频道限制

全服务器频道限制属于合集级别，并应用于其中的所有条目。可以在合集状态按钮旁的 `频道` 处进行设置。人格世界书则在每个条目上保留频道限制。频道留空表示允许在所有频道中使用；子区跟随其父频道。

合集的 `已启用` / `已关闭` 按钮控制整本世界书。将其关闭会使所有条目不在对话中生效，而不会改变每个条目自身的启用状态。重新启用合集会保留各个条目原有的启用或关闭状态。

由较旧的带关键词标签服务器记忆转换而来的某个人格世界设定，可能仍带有尚未解析的 `#channel` 名称。在管理员保存频道选择之前，TomoriBot 会将该条目视为在所有频道中均有效，并在世界书页面上对其进行标记。

## 导入世界书

在全服务器作用域下，在合集选择器中选择 `+ 导入世界书`，即可根据上传的文件创建一本世界书。其名称默认使用文件内的书名，其次使用文件名；你也可以在导入弹窗中输入名称。已存在的名称会被拒绝，因此导入新书不会覆盖已有世界书。在已选世界书的条目选择器中，使用 `+ 导入条目` 可以追加或替换其中的条目。

对于人格作用域，由于该人格拥有单独一本书，`+ 导入世界书` 保留在条目选择器中。两种导入均接受 SillyTavern 世界设定 JSON、角色书 JSON 以及 PNG、CHARX 或 JSON 格式的角色卡。在此处上传角色卡只会导入其中内嵌的角色书。没有角色书的卡片不会改变所选的世界书。

默认行为是追加：已存在的条目会被跳过，并添加新条目。勾选 `替换此世界书` 可仅替换所选的世界书。其他全服务器世界书保持不变。每个人格最多可容纳 250 条条目，全服务器世界书共享独立的 250 条条目上限；超出该上限的导入会被整体拒绝，不会出现仅导入一部分的情况。JSON 文件限制为 2 MB；PNG 和 CHARX 卡片使用上传弹窗中显示的宿主家人格导入限制。

回执会显示添加了多少条条目以及跳过了多少条。跳过的计数包括重复项以及转换器无法使用的条目（例如没有内容的条目）。没有对应目标的设置（例如分组、递归、黏性计时器、冷却时间与触发器）会被统计并丢弃。第 2 到第 7 个世界设定位置会放在人格之前。正则表达式关键词保持原样不激活。导入回执会标明不支持的关键词与设置。

卡片中的角色书会由 `/persona import` 作为该人格的世界书导入；请参阅[SillyTavern 支持](/features/integrations/sillytavern-support/)。

## 导出世界书

在条目选择器中选择 `+ 导出世界书`，会将选中的全服务器世界书或人格世界书下载为 SillyTavern 世界设定 JSON。可以通过相同的世界书上传重新导入它。条目的生效设置与各个条目的启用状态会随文件一起导出；频道限制、待解析的频道名称以及合集状态则不会包含在内。

如果需要保留这些限制与合集设置的服务器备份，请使用 `/export memories` 并选择 `所有人格`。`主人格` 与 `选中的人格` 仅导出记忆，并在导入时保持目标世界设定不变。
