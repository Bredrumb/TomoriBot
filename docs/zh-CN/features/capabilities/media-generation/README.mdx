TomoriBot 可以直接在聊天里创作媒体：**图像、短视频和语音
消息**。用大白话让她做就行（「给我画一个……」，「把那个用语音消息发出来」），或者
用 `/generate` 系列指令。哪些功能可用取决于你配置的
提供方；见[提供方与模型](/zh-CN/features/setup-administration/providers-and-models/)。

  <LinkCard title="视频生成" href="/zh-CN/features/capabilities/media-generation/video-generation/"
    description="可自定义画面比例的短篇文生视频与图生视频。" />
  <LinkCard title="语音：TTS 与 STT" href="/zh-CN/features/capabilities/media-generation/tts-and-stt/"
    description="Discord 原生语音消息（文本转语音）与音频转写（语音转文字）。" />
</CardGrid>

:::note
并不是每个提供方都支持每项功能。本地生成（ComfyUI、本地语音
服务器）在自部署实例上可用；见[自部署](/en/self-hosting/)。
:::
