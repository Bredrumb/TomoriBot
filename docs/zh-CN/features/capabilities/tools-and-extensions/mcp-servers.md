[MCP](https://modelcontextprotocol.io/)（Model Context Protocol）服务器可以通过你自行注册的外部工具来扩展她的能力。

### 添加在线 MCP

使用提供方直接提供的、支持 MCP Streamable HTTP 或 SSE 的 HTTPS 端点：

在 `/config` > `插件` > `MCP 服务器` 下添加该端点以及所需的身份验证信息。如果你要添加用于回复审核的规则检查器，请选择 `文本校对器`；其中的工具不会在聊天期间被调用。

认证令牌在静态存储时会经过加密。停用当前用于搜索或读取 URL 的服务器后，系统会恢复使用内置工具。已保存的工具列表反映的是上一次成功发现的结果，并不保证该服务器当前仍可访问。

工具响应体积上限为 8 MiB（对于 SSE 连接，该上限包含整个数据流）。如果工具返回超出限制，请向提供方请求分页或缩小返回结果。

### 添加需要登录的 MCP

部分服务（例如 Linear 和 Notion）会要求你登录账号，而不是直接提供令牌。添加此类 MCP 时请将 `认证令牌` 留空。当服务器请求登录时，面板会显示一个 `登录` 按钮：

1. 选择 `登录`，并在 10 分钟内完成该服务的登录。
2. 确认页面会列出你的 Discord 服务器名称与该 MCP 的地址。仅当两者均正确，且此次登录确实由你本人发起时，才选择 `连接`。
3. MCP 添加完成后，Discord 中的面板会自动更新。

每位使用该 MCP 工具的成员都会以登录账号的身份执行操作，因此请使用一个允许整个服务器查看其数据的账号。

当登录过期或服务要求更多权限时，该 MCP 的工具会暂停使用，其对应条目会显示 `重新连接`。选择它并重新登录即可，MCP 原有的名称、类型和槽位均会保留。

登录功能仅支持在服务器中添加 MCP 时使用，不支持在私信中使用。在自部署 bot 上，宿主需要先完成配置；请参阅 [MCP 登录配置](/self-hosting/mcp-servers/mcp-sign-in/)。

### 本地 MCP 服务器

仅自部署实例支持本地 MCP 服务器，因为公开托管的 bot 要求使用 HTTPS，且会阻止本地与私有地址。如果你运行着自己的实例，请参阅[配置：本地 MCP 服务器](/self-hosting/mcp-servers/setup-local-mcp/)。

:::danger[仅添加你信任的 MCP 服务器]
恶意 MCP 服务器可能会向她注入隐藏的提示词指令、窃取用户传递给工具的数据，或返回有害与虚假的结果并由她转达给你的服务器。请像对待浏览器扩展一样谨慎对待 MCP 服务器：只要有疑虑，就不要添加。添加前务必先检查该 MCP 描述的工具内容。
:::
