使用随附的[WhisperX](https://github.com/m-bain/whisperX)服务器为TomoriBot配置本地、高准确率的语音识别。WhisperX提供带词级时间戳对齐的快速音频转写。

## 安装配置

在TomoriBot仓库根目录下运行以下命令：

<Tabs syncKey="operating-system">
<TabItem label="Windows">

```powershell
cd servers/stt
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python whisperx_server.py
```

请确保`ffmpeg`位于你的`PATH`中。若要使用NVIDIA GPU加速，CUDA 12的cuBLAS和cuDNN DLL也必须位于你的`PATH`中。

</TabItem>
<TabItem label="Linux">

```bash
cd servers/stt
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python whisperx_server.py
```

请确保已安装`ffmpeg`（在Debian/Ubuntu上运行`sudo apt-get install ffmpeg`）。在配备NVIDIA GPU的系统上，CUDA 12运行时库会启用GPU加速转写。

</TabItem>
<TabItem label="Mac">

```bash
cd servers/stt
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python whisperx_server.py
```

请确保已安装`ffmpeg`（`brew install ffmpeg`）。由于`servers/stt/requirements.txt`引用了`--extra-index-url https://download.pytorch.org/whl/cu124`（仅适用于Linux/Windows CUDA），`pip`在Mac上会回退到标准PyPI wheel。CTranslate2不使用Apple MPS，因此转写会在CPU上运行（默认精度为`int8`，如有需要也可设置`WHISPERX_COMPUTE_TYPE=float32`）。

</TabItem>
</Tabs>

当TomoriBot使用WhisperX期间，请保持该终端打开。默认端点URL为`http://127.0.0.1:8021`。在Windows上，请使用`127.0.0.1`代替`localhost`。

## 选择模型

在启动服务器前设置`WHISPERX_MODEL`：

<Tabs syncKey="operating-system">
<TabItem label="Windows">

```powershell
$env:WHISPERX_MODEL = "large-v3-turbo"
python servers\stt\whisperx_server.py
```

</TabItem>
<TabItem label="Linux">

```bash
WHISPERX_MODEL=large-v3-turbo python servers/stt/whisperx_server.py
```

</TabItem>
<TabItem label="Mac">

```bash
WHISPERX_MODEL=large-v3-turbo python servers/stt/whisperx_server.py
```

</TabItem>
</Tabs>

| `WHISPERX_MODEL` | 大小 | 用途 |
|---|---|---|
| `large-v3` | 1.55B | 多语言准确率最高；显存占用比turbo多约0.6 GiB |
| `large-v3-turbo` | 809M | 多语言，解码速度更快；日语效果略逊 |
| `kotoba-tech/kotoba-whisper-v2.0-faster` | 756M | 仅支持日语；在日语测试音频上比turbo更准确，速度相同 |

在短音频上编码器占主导地位，所以三者运行速度相近。按语言和显存选择即可。`small`和`base`损失了太多日语准确率，因此不作推荐。在极短或接近无声的音频上，Whisper模型仍可能会凭空编造文字。

## GPU与设备行为

当CUDA和CTranslate2均可用时，服务器会自动使用NVIDIA GPU。查看`http://127.0.0.1:8021/health`：在GPU环境下`device`会显示为`cuda`，在CPU与Mac环境下则会显示为`cpu`。

在Windows上，语音识别需要把CUDA 12的cuBLAS和cuDNN DLL添加到你的`PATH`。缺少它们时，服务器会在启动时输出`GPU found but unusable`并回退到CPU运行，速度会慢很多：请安装好它们并重启服务器。如果你设置了`WHISPERX_DEVICE=cuda`，服务器会在启动时直接中止而不会回退。

在Mac上，CTranslate2会在CPU上运行转写；设置`WHISPERX_DEVICE=cuda`会报错失败。

## 在TomoriBot中注册

运行`/providers`，选择`+ 添加新自定义端点`，并使用语音识别专用的API兼容性：

- API兼容性：`OpenAI 兼容语音识别`（`openai-compatible-transcription`）
- `端点 URL`：`http://127.0.0.1:8021`

保存连接后，选中它，并用它的模型下拉菜单把与`WHISPERX_MODEL`完全一致的值（默认为`large-v3`，或完整的仓库ID，例如`kotoba-tech/kotoba-whisper-v2.0-faster`）添加为语音识别模型。

端点注册和模型设置都在`/providers`里完成。之后打开`/config` > 模型 > 切换模型，选中并激活已注册的端点。

## 使用转写文本

注册后，TomoriBot会在后台转写音频附件并将文字添加到聊天上下文中。只有在你还希望将转写结果直接发送显示在聊天频道里时，才需要前往`/config` > 行为 > 提示行为中开启对应开关。
