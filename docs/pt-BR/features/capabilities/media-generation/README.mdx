A TomoriBot pode criar mídia diretamente no chat — **imagens, vídeos curtos e mensagens de voz
falada**. Peça a ela em linguagem natural ("desenhe para mim um...", "envie isso como mensagem de voz") ou
use os comandos `/generate`. Quais capacidades estão disponíveis depende do seu provedor
configurado — veja [Provedores & Modelos](/pt-BR/features/setup-administration/providers-and-models/).

:::note
Nem todo provedor suporta todas as capacidades. Geração local (ComfyUI, servidores de voz
locais) está disponível em instâncias de hospedagem própria — veja [Hospedagem Própria](/pt-BR/self-hosting/).
:::
