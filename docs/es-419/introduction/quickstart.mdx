Esta guía te lleva desde cero hasta tu primer mensaje con TomoriBot. La forma más sencilla es invitar a la instancia pública lista para usar (consulta la [Política de privacidad](/es-419/legal/privacy-policy/)). Si prefieres ejecutar tu propia instancia, ve a [Autoalojamiento](#autoalojamiento) al final.

## Usar el bot alojado

### Paso 1: Invítala

Invita a la instancia pública con el botón de abajo y luego elige el servidor donde la quieres.
Necesitas el permiso Administrar servidor para añadir un bot.

  <LinkButton href="https://discord.com/oauth2/authorize?client_id=841644102059556915" variant="primary">
    Invitar a TomoriBot
  </LinkButton>
</div>

También puedes enviarle un mensaje directo. Los pasos de configuración son los mismos.

### Paso 2: Obtén una clave de API

TomoriBot no incluye un cerebro de IA propio. Conectas uno de un proveedor mediante una clave de API. Es compatible con muchos proveedores y solo necesitas uno para comenzar. Estos son algunos de los proveedores compatibles actualmente:

- **Google Gemini**: de propósito general, tiene un nivel gratuito y ejecuta todas las funciones. Recomendado para tu primera configuración.
- **OpenRouter**: una clave para acceder a los modelos más recientes de texto, video, imagen y embeddings.
- **NovelAI**: basado en suscripción, con imágenes sin censura, rol y narrativa.
- DeepSeek, NVIDIA NIM, Anthropic, Vertex AI, Z.ai o cualquier endpoint Custom compatible con OpenAI.

Ejecuta `/help` en Discord, elige `Configuración`, luego Paso 1: Obtener una clave de API y selecciona tu proveedor para saber cómo obtener su clave de API, o consulta [Proveedores y modelos](/es-419/features/setup-administration/providers-and-models/#api-keys) para ver la lista completa.

<Aside type="caution">
Nunca compartas tu clave de API con nadie. Proporciónala únicamente mediante los comandos de barra de TomoriBot, que la almacenan y cifran de forma segura.
</Aside>

### Paso 3: Ejecuta la configuración

Ejecuta `/setup`. Se abre un panel privado con una lista de verificación que solo tú puedes usar. Completa sus elementos y luego presiona `Finalizar configuración`:

- **Proveedor de IA**: elige `Proveedor de IA (recomendado)`, selecciona tu proveedor y pega la clave. Quienes usen autoalojamiento pueden elegir `Punto de conexión personalizado` para registrar la conexión y el modelo de texto de su endpoint. En un servidor, `BYOK de usuario` permite que cada miembro proporcione su propio proveedor personal.
- **Ajustes iniciales**: elige una persona inicial, un estilo de respuesta, una zona horaria y el prompt de sistema predeterminado.
- Políticas (solo instancias alojadas): acepta los Términos de servicio y la Política de privacidad en un modal.

No se guarda nada mientras trabajas: el panel es un borrador. `Finalizar configuración` cifra la clave, inicializa la configuración del servidor y la prepara para conversar. `Cancelar` descarta el borrador, y un panel intacto vence por sí solo. Cada servidor conserva su propia configuración independiente.

Recomendado: ejecuta `/expressions initialize` después para que pueda usar correctamente los emojis y stickers personalizados de tu servidor.

### Paso 4: Comienza a chatear

Solo menciónala o responde a uno de sus mensajes:

```text
@TomoriBot hola, ¿qué tal?
```

Desde aquí puedes definir cómo se activa y cómo se comporta:
- Dale una personalidad con `/persona`: consulta [Múltiples personas](/es-419/features/chatting-personality/multiple-personas/).
- Enséñale con `/memories`: consulta [Memoria](/es-419/features/knowledge/memory/long-term-memory/).
- Explora otras opciones de personalización: consulta [Referencia de comandos](/es-419/features/command-reference/) o [Funciones](/es-419/features/).

En la instancia alojada, configurar TomoriBot significa que tú y los miembros de tu servidor aceptan sus avisos de `/legal terms-of-service` y `/legal privacy-policy`. La configuración guiada te pide aceptar ambos. Esos dos comandos y el paso Políticas que los contiene pertenecen al despliegue alojado. Una instancia autoalojada registra `/legal license` en todos los entornos y las dos políticas solo bajo `RUN_ENV=production`.

## Autoalojamiento

Si prefieres tener control total sobre tu privacidad y tus datos, puedes ejecutar tu propia instancia de TomoriBot en tu propio hardware:

- **Opción 1: Asistente de instalación (Recomendado)**: requiere [Bun](https://bun.sh/) v1.3.2+, [PostgreSQL](https://www.postgresql.org/) o [Docker](https://www.docker.com/) y un [token de bot de Discord](https://discord.com/developers/applications) con `Presence Intent`, `Server Members Intent` y `Message Content Intent` habilitados:
  ```sh
  git clone https://github.com/Bredrumb/TomoriBot.git
  cd TomoriBot
  bun run setup # instala dependencias, configura .env y prepara PostgreSQL
  bun run dev # inicia el bot y ejecuta las migraciones de la base de datos automáticamente
  ```
- **Opción 2: Docker Compose**: requiere [Docker](https://www.docker.com/) y Docker Compose v2+, y un [token de bot de Discord](https://discord.com/developers/applications) con los mismos tres intents habilitados (consulta la [guía de Docker Compose](/self-hosting/docker-compose/) para conocer las variables de `.env` requeridas y los permisos de directorio en Linux):

<Tabs syncKey="operating-system">
<TabItem label="Windows">

```powershell

cd TomoriBot
Copy-Item .env.example .env
```
