このガイドでは、TomoriBotでの最初のメッセージまでをゼロから案内します。準備済みの公開インスタンスを招待するか、独自のインスタンスをセルフホストしてから、Discord内でセットアップを完了できます。

## 1. DiscordにTomoriBotを追加する

### 方法A：ホストされたBotを招待する

手軽に使いたい場合は、下のボタンから公開インスタンスを招待し、参加させたいサーバーを選択します（直接DMを送ることもできます）。
Botを追加するには、`サーバー管理`権限が必要です。

### 方法B：ご自身でセルフホストする

プライバシーやデータを完全に制御したい場合は、ご自身のハードウェアで独自のTomoriBotインスタンスを稼働させることができます：

- **方法1：セットアップウィザード（推奨）**：[Bun](https://bun.sh/) v1.3.2以上、[PostgreSQL](https://www.postgresql.org/)または[Docker](https://www.docker.com/)、および`Presence Intent`、`Server Members Intent`、`Message Content Intent`が有効な[Discord Botトークン](https://discord.com/developers/applications)が必要です：
  ```sh
  git clone https://github.com/Bredrumb/TomoriBot.git
  cd TomoriBot
  bun run setup # 依存関係のインストール、.envの設定、PostgreSQLのセットアップを行います
  bun run dev # Botを起動し、データベースのマイグレーションを自動実行します
  ```
- **方法2：Docker Compose**：[Docker](https://www.docker.com/)およびDocker Compose v2以上と、同じ3つのIntentが有効な[Discord Botトークン](https://discord.com/developers/applications)が必要です（必要な`.env`変数とLinuxのディレクトリ権限については、[Docker Composeガイド](/self-hosting/docker-compose/)を参照してください）：

## 2. `/setup`を実行する

`/setup`を実行し、すべての項目を完了してから`セットアップを完了`を押します：

- **AIプロバイダー**：`AIプロバイダー（推奨）`を選択し、プロバイダーを選んでキーを貼り付けます。セルフホストの場合は`カスタムエンドポイント`を選択してエンドポイント接続とテキストモデルを登録できます。サーバーでは、`ユーザーBYOK`によって各メンバーが個人のプロバイダーを提供できます。
- **初期設定**：初期ペルソナ、返信スタイル、タイムゾーン、デフォルトのシステムプロンプト、および追加機能を選択します。9つの追加機能はすべて初期状態でチェックが入っているため、不要なものはチェックを外してください。これらの設定は後から`/config`で調整できます。

作業中は何も保存されません。パネルは下書きであり、`セットアップを完了`を押すことでキーが暗号化され、サーバー用の設定が初期化されて会話の準備が整います。`キャンセル`を押すと下書きは破棄され、操作されないパネルは自動的に期限切れになります。各サーバーは独自の独立した設定を保持します。

推奨の次のステップとして、`/expressions initialize`を実行し、サーバーのカスタム絵文字やスタンプを正確に使用できるようにしてください。

## 3. チャットを開始する

メンションするか、メッセージに返信してください（または直接DMを送って挨拶してください）：

```text
@TomoriBot やあ、調子はどう？
```

### 基本コマンドと次のステップ

- `/setup`：サーバーの初期ボットセットアップ。
- `/config`および`/personal config`：現在のDiscordサーバーまたは個人向けにTomoriBotを調整します。
- `/providers`および`/personal providers`：モデルエンドポイントやクラウドプロバイダーを追加します。
- `/persona`：性格を与えたり、新しいキャラクターを追加したりします。[複数のペルソナ](/features/chatting-personality/multiple-personas/)をご覧ください。
- `/memories`：会話を通じて事実を教えます。[記憶](/features/knowledge/memory/long-term-memory/)をご覧ください。

その他のカスタマイズオプションは、[コマンドリファレンス](/features/command-reference/)や[機能](/features/)ツアーをご覧ください。
