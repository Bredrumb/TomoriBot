TomoriBotはアクティブなチャンネルの最近のメッセージを読み取ります。短期記憶（STM）は一時的な作業コンテキストを維持することで、これを拡張します：

- **チャンネルコンテキスト：** 現在のチャンネルで進行中のトピックや状況を強化します。
- **チャンネル間コンテキスト：** 他のチャンネルでの最近の会話、およびサーバー間呼び出しが有効な場合は他のサーバーでの会話を呼び出します。

彼女は自分が参加した会話のみを記憶します。彼女が返信したときにのみチャンネルの要約を更新するため、誰も彼女に話しかけない賑やかなチャンネルには記憶が残りません。各チャンネルの短期記憶はデフォルトで24時間後に期限切れになります。`/personal config` でオプトアウトしている場合、あなたのメッセージは短期記憶から除外されます。

最新の短期記憶および他チャンネルの内容を含む記憶は、直近4発言ターンの直上に配置されます。デフォルト設定では、このチャンネルの古い記憶は会話の上部に留まります。より浅い深度を設定することで、コンテンツを最新のメッセージのより近くに保持できます。全体のレイアウトについては [プロンプトの中身](/features/knowledge/inside-the-prompt/) を参照してください。

## チャンネル間の例

- **公開チャンネル：** あなたが `#music` でTomoriBotとアルバムのおすすめについて話します。数分後、`#general` で彼女がおすすめしたアルバムを尋ねます。彼女は `#music` で返信したため、そのコンテキストを `#general` で呼び出します。
- **プライベートチャンネル：** その会話がプライベートチャンネルで行われた場合、彼女は `#general` でそれを呼び出しません。管理者が `/config` > `権限` でSTMプライバシーバイパスを有効にしない限り、プライベートチャンネルの要約は分離されたままになります。

## 短期記憶の管理
<!-- anchor: managing-short-term-memory -->

`/config` > `ペルソナ` > `記憶` で、現在のチャンネルの要約を確認または修正できます。
サーバー管理者は `/config` > `動作` > `高度な記憶` でパラメータの調整や短期記憶の無効化を行え、`/memories` > `短期記憶` でアクティブなチャンネルの要約の確認や消去ができます。
`/refresh` は現在のチャンネルの記憶を消去します。
