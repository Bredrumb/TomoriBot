長期記憶は、誰かが削除するまでTomoriBotが保持する短い事実です。`/refresh` や再起動を行っても失われません。彼女はまた、[ドキュメント](/features/knowledge/memory/documents/)、[ロアブック](/features/knowledge/memory/lorebooks/)、[短期記憶](/features/knowledge/memory/short-term-memory/)を通じても記憶を保持します。`/memories` にはそれぞれに対応するタブがあります。性格や行動については、[マルチペルソナ](/features/chatting-personality/multiple-personas/)を参照してください。

## 個人とサーバーの記憶
<!-- anchor: personal-vs-server-memories -->

個人の記憶は、あなたについての事実です。サーバーをまたいであなたに追従し、あなたが会話に参加しているときに使用されます。サーバーの記憶には、そのサーバーの全員に向けた情報が含まれます。

各ペルソナは、個人の記憶とサーバーの記憶をそれぞれ独自に保持します。`/personal memories` のGlobalページから追加された個人の記憶は、すべてのペルソナに適用されます。個人の記憶は `/personal memories` で、サーバーの記憶は `/memories` で管理します。

対応するメッセージプロキシサービスを使用すると、TomoriBotは検証済みのプロキシIDに対して個別の個人の記憶を保持できます。ホストのDiscordアカウントがプライバシーと認可を管理します。設定と制限事項については、[メッセージプロキシ対応](/features/integrations/message-proxy-support/)を参照してください。

## 記憶の保存

記憶は自分で保存することも、会話中にTomoriBotが保存を判断することもできます。彼女が記憶を保存すると、何を学んだかを確認する埋め込みを投稿します。その確認がない場合、その情報は長期記憶ではなく会話履歴に留まります。

彼女に何かを保存してほしい場合は、覚えておくよう頼むか、自分で追加してください。サーバー管理者は `/config` > `権限` で自動保存を無効にできます。

## 記憶の制限
<!-- anchor: how-many-memories -->

各ペルソナは、デフォルトで個人の記憶100件とサーバーの記憶100件を保持できます。Globalの個人の記憶は、各ペルソナの個人制限枠に対して計上されます。セルフホスト管理者は `MAX_PERSONAL_MEMORIES`、`MAX_SERVER_MEMORIES`、`MAX_MEMORY_LENGTH` で制限を変更できます。

:::tip
長い記憶を少なく持つより、短い記憶を多く持つほうが望ましいです。引き上げられた `MAX_MEMORY_LENGTH` を使用する記憶は、アクティブになるたびに全文が送信されますが、`MAX_PERSONAL_MEMORIES` や `MAX_SERVER_MEMORIES` の追加スロットは埋まるまでコストがかかりません。長い参照テキストは [ドキュメント](/features/knowledge/memory/documents/) に適しており、全文を送信する代わりに検索が行われます。
:::

### 記憶の減衰

埋め込みモデルが設定されている場合、会話に一致しないまま7日間の会話日数を経過した記憶は休眠状態になります：記憶は保存されたまま残りますが、以降のメッセージで再び呼び出されるまで通常のプロンプトからは除外されます。記憶枠が上限に達している場合、自動保存によって休眠中の記憶が忘れられることがありますが、Globalの個人の記憶や、誰かが `/memories` または `/personal memories` で追加・編集した記憶が忘れられることは決してありません。[記憶の減衰](/features/knowledge/memory/memory-decay/) を参照してください。

常に適用すべき指示については、[ペルソナ属性](/features/chatting-personality/multiple-personas/#attributes)、ペルソナプロンプト、または [常時有効（Always On）のロアブックエントリ](/features/knowledge/memory/lorebooks/) を使用してください。

## 記憶が有効化される条件の制御
<!-- anchor: controlling-when-memories-activate -->

アクティブな記憶は、その所有者とスコープが会話に一致したときに含まれます。休眠中の記憶は、関連性がある場合に検索を通じて呼び戻されます。チャンネル制限によって適用場所を絞り込むことができ、個人の記憶ではキーワードタグも使用できます。

### 個人の記憶のタグ
<!-- anchor: keyword-tags -->

個人の記憶には、キーワードタグまたは `#channel` タグを付けることができます。タグ付けは `/config` > `動作` > `高度な記憶` で有効にします。有効にすると、タグ付きの個人の記憶はそのキーワードのいずれかが会話に現れたときにのみ表示され、タグのない記憶はアクティブなまま維持されます。`#channel` タグはそのチャンネルのみに制限します。現在どの記憶がアクティブであるかを確認するには `/tool prompt snapshot` を使用します。

サーバーの記憶ではキーワードタグを使用しなくなりました。作成された設定情報は [ロアブック](/features/knowledge/memory/lorebooks/) に属し、エントリごとにキーワードや常時有効（Always On）を設定します。

### チャンネル

サーバーの記憶とドキュメントは、選択したチャンネルとそのスレッドに制限できます。個人の記憶は `#channel` タグを使用します。ロアブックエントリでもチャンネルの選択が可能です。

以前のサーバーの記憶やドキュメントの `#channel` タグは、チャンネル選択に変換されました。タグ付けされたチャンネルがすでに存在しない場合、その項目はすべてのチャンネルでアクティブなまま残ります。`/memories` でこれらの項目が示されるため、新しいチャンネルを選択できます。

## 条件付け
<!-- anchor: conditioning -->

条件付けは、サーバー内でのペルソナの行動を誘導します。理由を添えてペルソナに与えられた報酬や罰は、彼女が行動の指針とできる条件付けになります。理由のないインタラクションは集計されますが、プロンプトには表示されません。条件付けの確認やクリアは `/conditioning` で行います。

遊びのインタラクションによって、ペルソナがユーザーや他のペルソナに報酬や罰を与えることもできます。ユーザーに対するインタラクションでは条件付けは保存されません。ペルソナに対するインタラクションでは、そのペルソナが応答するよう促すことができます。サーバー管理者は `/config` > `プラグイン` > `利用可能なツール` でこのツールを無効にできます。

## プライバシー

TomoriBotが保存する内容や、そのエクスポートおよび削除方法については、[データ処理](/features/knowledge/data-handling/) および `/legal privacy-policy` を参照してください。`/personal config` で記憶からオプトアウトできます。
