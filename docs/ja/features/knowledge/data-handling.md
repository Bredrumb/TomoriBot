Discordスラッシュコマンドを使用して、設定、メモリ、ペルソナをエクスポート、バックアップ、インポート、または削除します。サービス条件とプライバシーの詳細については、`/legal terms-of-service`および`/legal privacy-policy`を参照してください。

:::note
このページでは、Discord内のユーザー コントロールについて説明します。セルフホスト型インスタンスでは、データベースの完全バックアップと復元はホスト側の操作です。[メンテナンスとバックアップ](/ja/self-hosting/maintenance/)を参照してください。
:::

## 彼女が保管しているもの

### 保存データ

- サーバーと個人の思い出
- ペルソナのプロフィール、特徴、会話例
- サーバー構成設定
- 暗号化されたプロバイダー APIキー
- 表現メタデータ、ペルソナアクセスルール、およびアップロードされた表現メディア

### 保存されていない

- Discordメッセージ履歴 (メッセージは永続メッセージログにアーカイブされません)

### AIプロバイダーに送信されます

トリガーされるたびに、TomoriBotはチャネル内の最近のメッセージを、モデルのコンテキストとして関連するメモリとともにフェッチします。彼女は、これらのトリガー以外のメッセージを読んだり処理したりしません。

:::note
選択したAIプロバイダー (Google、OpenRouter、NovelAIなど) は、独自のプライバシー ポリシーに基づいてメッセージを処理します。機密性の高い個人認証情報や機密データを共有しないでください。
:::

## データのエクスポート

エクスポート可能なデータは、JSONファイルとしてDMに配信されます。

- `/export config`: サーバー構成値 (APIキーと資格情報を除く)。
- `/export personal config`: 個人プロファイル設定 (プライバシー、外観タグ、名前付け)。
- `/export memories`: サーバー メモリ。メインペルソナ、1つのペルソナ、またはすべてのペルソナにスコープされます。
- `/export personal memories`: グローバルまたは個人ごとの個人的な思い出。
- `/persona export`: 完全なペルソナ定義。

アップロードされた式メディアはサーバー ホストに保存され、これらのJSONエクスポートの外部にあります。セルフホスティング者は、データベースストレージとメディア資産を一緒にバックアップする必要があります。[カスタムメディアバックアップ](/ja/self-hosting/safe-migration/#custom-expression-media-backups) を参照してください。

## データのインポート

エクスポートしたファイルを添付して復元します。

- `/import config`: サーバー構成 (サーバーの管理が必要)。適用するセクションを選択します。
- `/import personal config`: 個人設定。検出されたセクションを適用するかを選択します。
- `/import memories`: サーバー メモリ (サーバーの管理が必要)。ペルソナを結合または置換し、マップします。
- `/import personal memories`: 個人的な思い出。ペルソナを結合または置換し、マップします。
- `/persona import`: ペルソナを復元します。SillyTavern PNGカード、JSONカード、および`.charx`アーカイブもインポートします ([SillyTavernサポート](/ja/features/integrations/sillytavern-support/) を参照)。

## データの削除

これらのアクションにより、保存されたデータが完全に削除またはリセットされます。

- `/personal memories`: 個人の思い出を管理または削除します。
- `/memories`: サーバー メモリを管理または削除します (サーバーの管理が必要)。
- `/personal nuke`: サーバー全体のすべての個人データを完全に削除します。
- `/nuke`: カスタム表現やペルソナアクセスルールを含むサーバー データをワイプします。カスタム表現とメディアを削除しながらペルソナを維持するには、`preserve_personas: true`を設定します。
- `/reset config`: サーバー構成をデータベースのデフォルトに復元します。
  - **保持**: アクティブなモデル割り当て、APIキー、カスタムエンドポイント、ペルソナ、サーバー メモリ、および統合。
  - **クリア**: チャネルオーバーライド、自動トリガー ルール、ユーザー ブラックリスト、およびチャネルホワイトリスト。
  - サーバーのサーバー管理権限が必要です。DMでも受け付けております。
- `/reset personal config`: 個人プロファイル設定とチャンネルスポットライトをデフォルトに戻します。
  - **保持**: ユーザー ID、個人のメモリ、保存されたプロバイダー APIキー、カスタムエンドポイント、およびスケジュールされたタスク。
  - **クリア**: ニックネームの上書き、外観タグ、代名詞、アドレス指定スタイル、およびチャネルスポットライト。
  - サーバーおよびDMのすべてのユーザーが利用できます。

正確なデータベーステーブルと保存された列リストについては、[データベーススキーマアーキテクチャ](/en/architecture/subsystems/database-schema/#reset-domain-classifications) を参照してください。

## オプトアウト

- `/personal config`: 完全な非表示 (メモリコンテキストのオプトアウト) まで、表示を制御します。
- `/config` > `権限`: サーバー管理者は自己学習機能とメモリ機能をオフに切り替えることができます。

日常のメモリ管理については、[メモリ](/ja/features/knowledge/memory/) を参照してください。
