[MCP](https://modelcontextprotocol.io/)（Model Context Protocol）サーバーを使うと、ご自身で登録した外部ツールによってTomoriBotの機能を拡張できます。

### オンラインMCPの追加

MCP Streamable HTTPまたはSSEに対応した、プロバイダーの直接HTTPSエンドポイントを使用します：

`/config` > `プラグイン` > `MCPサーバー` で、エンドポイントと必要な認証情報を追加してください。下書きレビューのルールチェッカーとして使用する場合は `文章校正` を選択します。そのツールはチャット中に呼び出されることはありません。

認証トークンは保存時に暗号化されます。検索やURL取得に使用していたサーバーを無効化すると、組み込みのツールが復元されます。保存されているツール一覧は最後に成功した検出結果を反映したものであり、現在もサーバーに到達可能であることを保証するものではありません。

ツールのレスポンスは8 MiBまでに制限されており、SSE接続ではストリーム全体がこの上限に含まれます。ツールが上限を超える場合は、プロバイダー側にページネーションやより小さな結果を返却するよう設定・依頼してください。

### サインインが必要なMCPの追加

LinearやNotionなどの一部のサービスでは、トークンを発行する代わりにアカウントへのサインインが求められます。`認証トークン` を空欄のままにしてMCPを追加してください。サーバーがサインインを要求すると、パネルに `サインイン` ボタンが表示されます：

1. `サインイン` を選択し、10分以内にサービスへサインインします。
2. 確認ページには、お使いのDiscordサーバーとMCPのアドレスが表示されます。両方が正しく、かつご自身でこのサインインを開始した場合にのみ `接続` を選択してください。
3. MCPが追加されると、Discord上のパネルが更新されます。

MCPのツールを使用するすべてのメンバーは、サインインしたアカウントとして動作します。そのため、サーバー全体でデータを閲覧しても問題のないアカウントを使用してください。

サインインの有効期限が切れた場合や、サービス側が追加のアクセス権限を要求した場合は、そのMCPのツールが一時停止し、行に `再接続` が表示されます。`再接続` を選択して再度サインインすると、MCPの名前、タイプ、スロットを保持したまま復旧できます。

サインインはサーバー内でMCPを追加する場合にのみ機能し、DMでは利用できません。セルフホストボットの場合は、先にホスト側での設定が必要です。[MCPサインインのセットアップ](/self-hosting/mcp-servers/mcp-sign-in/)を参照してください。

### ローカルMCPサーバー

公開ホスト型ボットはHTTPSを必須とし、ローカルおよびプライベートアドレスをブロックするため、ローカルMCPサーバーはセルフホストインスタンスでのみサポートされます。ご自身のインスタンスを運用している場合は、[セットアップ：ローカルMCPサーバー](/self-hosting/mcp-servers/setup-local-mcp/)を参照してください。

:::danger[信頼できるMCPサーバーのみを追加してください]
悪意のあるMCPサーバーは、隠された指示によるプロンプトインジェクション、ユーザーがツールへ渡したデータの外部送信、あるいはサーバーへそのまま中継される有害または虚偽の結果の返却を行う恐れがあります。MCPサーバーはブラウザー拡張機能と同様に扱い、少しでも疑わしい場合は追加しないでください。追加する前には、必ずMCPが公開するツールの説明を確認してください。
:::
