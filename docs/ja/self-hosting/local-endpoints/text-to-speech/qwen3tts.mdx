[Qwen3-TTS](https://github.com/QwenAudio/Qwen3-TTS) を使用して、音声クローンモードとテキスト指定のVoiceDesignモードの両方で高精度な多言語キャラクター音声を合成します。

Qwen3-TTS 12Hz 1.7Bは、高精度なローカル音声合成を提供します。`servers/tts/qwen3tts/server.py` をデフォルトの自動モードで実行すると、各受信リクエストに基づいてBase音声クローンモデルまたはVoiceDesignモデルが動的に選択されます。

## セットアップ

TomoriBotリポジトリのルート（TomoriBotをクローンしたフォルダー）から以下のコマンドを実行します：

<Tabs syncKey="operating-system">
<TabItem label="Windows">

```powershell
python -m venv servers\tts\qwen3tts\.venv
servers\tts\qwen3tts\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r servers\tts\qwen3tts\requirements.txt
python servers\tts\qwen3tts\server.py
```

NVIDIA GPUでは、デフォルトの`cuda-graphs`バックエンドが自動的に動作します。CPU専用マシンでは、`server.py`を起動する前に`$env:QWEN3TTS_BACKEND = "transformers"`を設定してください。

</TabItem>
<TabItem label="Linux">

システムにまだインストールされていない場合は`sox`をインストールし（Debian/Ubuntuでは`sudo apt-get install -y sox`）、仮想環境を作成してサーバーを起動します：

```bash
python3 -m venv servers/tts/qwen3tts/.venv
source servers/tts/qwen3tts/.venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r servers/tts/qwen3tts/requirements.txt
python servers/tts/qwen3tts/server.py
```

NVIDIA GPUでは、デフォルトの`cuda-graphs`バックエンドが自動的に動作します。CPUまたはAMD ROCm GPUでは、`QWEN3TTS_BACKEND=transformers`を設定してください（AMD GPUの場合は`.venv`内に互換性のあるROCm版PyTorchビルドもインストールしてください）。

</TabItem>
<TabItem label="Mac">

まずHomebrewで`sox`をインストールし、その後仮想環境を作成して標準の`transformers`バックエンドでサーバーを起動します（`cuda-graphs`にはNVIDIA CUDA GPUが必要であり、macOSでは`pip`が標準のPyPI PyTorchホイールにフォールバックします）：

```bash
brew install sox
python3 -m venv servers/tts/qwen3tts/.venv
source servers/tts/qwen3tts/.venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r servers/tts/qwen3tts/requirements.txt
QWEN3TTS_BACKEND=transformers python servers/tts/qwen3tts/server.py
```

CUDAがない場合、デフォルトではサーバーは`float32`で`cpu`上に実行されます。Apple Siliconでは`QWEN3TTS_DEVICE_MAP=mps`と`QWEN3TTS_DTYPE=float32`を試すこともできますが、標準PyTorch MPSのスループットはNVIDIA CUDAよりはるかに遅く、リポジトリのテスト対象外です。

</TabItem>
</Tabs>

TomoriBotがQwen3-TTSを使用している間はそのターミナルを開いたままにしてください（または後で`bun run launch --qwen3tts`で起動します）。デフォルトの自動モードのエンドポイントURLは`http://127.0.0.1:8012`です。別のポートを使用する場合は`QWEN3TTS_PORT`を設定してください。`--mode auto`を指定して自動モードを明示的に指定することもできます。

自動モードは各 `/synthesize` リクエストを検査します。`ref_audio` を持つリクエストはクローンモデルを使用し、`instruct` を持つリクエストはVoiceDesignモデルを使用します。一度にロードされるモデルは1つだけであり、リクエストの種類が変わるとモデルが入れ替えられるため、入れ替え後の最初のリクエストは遅くなる可能性があります。

## 高速なCUDAバックエンド

デフォルトでサーバーは、要件ファイルによりインストールされる[faster-qwen3-tts](https://github.com/andimarafioti/faster-qwen3-tts)を使用します。NVIDIA GPU上では標準バックエンドより約6倍高速に合成し、実時間の約2倍遅かった状態からリアルタイムより高速に音声を生成します。追加設定は不要ですがNVIDIA GPUでのみ動作し、CPU、Mac、またはAMD GPUでは起動時にサーバーが停止してバックエンドを切り替えるよう通知します。

このバックエンドは、リクエストごとに一定量の音声領域を確保し、参照クリップと生成された音声の間で共有します（合計約170秒）。10-20秒のクリップを使用した場合、2分を優に超える音声の余裕が残ります。リクエストが収まらない場合、サーバーは音声を途中で切り詰めるのではなくエラーを返します。より短いクリップやテキストを使用するか、標準バックエンドを使用してください。

代わりに標準バックエンドを使用するには、サーバーを起動する前に`QWEN3TTS_BACKEND=transformers`を設定します：

<Tabs syncKey="operating-system">
<TabItem label="Windows">

```powershell
$env:QWEN3TTS_BACKEND = "transformers"
python servers\tts\qwen3tts\server.py
```

</TabItem>

```bash

```

</TabItem>

## TomoriBotへの登録

ほとんどのユーザーは、1つのエンドポイントで音声クローンとVoiceDesignの両方のペルソナをサポートできるように、自動モードサーバーを登録します。

`/providers` を実行し、`+ 新しいカスタムエンドポイントを追加` を選択して、音声用のAPI互換性を使用します：

- API互換性：`tts-clone`
- `endpoint_url`：`http://127.0.0.1:8012`

接続を保存したら、それを選択し、モデルのドロップダウンを使用して音声モデルを追加します。モデルフォームで「音声ソースモード」と「スクリプトマークアップ形式」が求められるので、自動モードサーバーの場合は「自動」と「プレーン」を選択します。

エンドポイントの登録とモデルのセットアップには `/providers` を使用します。続いて `/config` > モデル > モデルの切り替え を開き、登録したエンドポイントを選択して有効化してください。

## ペルソナ音声のセットアップ

### 音声クローン

参照クリップを模倣するペルソナにこれを使用します：

1. 単一話者でBGMのない、きれいな10〜20秒の音声クリップを準備します。
2. `/config` の モデル > TTSパラメーターと音声 を開き、クリップをアップロードします。
3. `/config` の ペルソナ > 音声 を開き、ペルソナと音声サンプルを選択します。

Qwen3-TTSは、わずか3秒の短い参照クリップをサポートしています。

### VoiceDesign

サンプルの代わりに書かれた音声の説明を使用するペルソナにこれを使用します：

1. `/config` の ペルソナ > 音声 を開き、VoiceDesignを選択します。
2. ペルソナを選択します。
3. 話者の年齢、口調、アクセント、話し方などの自然言語による音声プロンプトを入力します。

## オプション：VoiceDesign専用サーバー

`Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign`を提供する場合は、同じサーバーをVoiceDesignモードで起動します（NVIDIA以外のハードウェアでは`QWEN3TTS_BACKEND=transformers`を追加してください）：

<Tabs syncKey="operating-system">
<TabItem label="Windows">

```powershell
servers\tts\qwen3tts\.venv\Scripts\Activate.ps1
$env:TOMORI_TTS_MODE = "voice-design"
python servers\tts\qwen3tts\server.py
```

</TabItem>
<TabItem label="Linux">

```bash
source servers/tts/qwen3tts/.venv/bin/activate
TOMORI_TTS_MODE=voice-design python servers/tts/qwen3tts/server.py
```

</TabItem>
<TabItem label="Mac">

```bash
source servers/tts/qwen3tts/.venv/bin/activate
QWEN3TTS_BACKEND=transformers TOMORI_TTS_MODE=voice-design python servers/tts/qwen3tts/server.py
```

</TabItem>
</Tabs>

`TOMORI_TTS_MODE` を設定する代わりに、`--mode voice-design` を渡すこともできます。デフォルトのVoiceDesign専用エンドポイントURLは `http://127.0.0.1:8014` です。

自動モードと同じ方法で登録しますが、エンドポイントURLには `http://127.0.0.1:8014` を使用し、音声モデルの音声ソースモードとして `ボイスデザイン` を選択します。
