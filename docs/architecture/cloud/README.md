Cloud docs describe how TomoriBot's production infrastructure runs on cloud provider
services (Azure, AWS, GCP): deployment targets, log/metric ingestion, and the operational
rules around them. Provider-agnostic hosting on your own machines lives under
[Self-Hosting](/self-hosting/) instead.
