Tất cả những gì TomoriBot có thể làm, được nhóm theo mục tiêu sử dụng của bạn. Mỗi thẻ đều liên kết
đến hướng dẫn đầy đủ. Bạn muốn xem trực tiếp trong Discord? Hãy chạy lệnh `/help`, sau đó mở `Tính năng` dưới mục `Thiết lập` để xem danh sách
tính năng đang hoạt động, hoặc dùng `/help` để duyệt qua từng lệnh.
