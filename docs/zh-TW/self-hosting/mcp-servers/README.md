設定你自架的 TomoriBot，以支援 OAuth 登入流程，或在旁同時運行本機 Model Context Protocol（[MCP](https://modelcontextprotocol.io/)）伺服器。

| 指南 | 用途 |
|---|---|
| [MCP 登入設定](/self-hosting/mcp-servers/mcp-sign-in/) | 設定 `TOMORI_PUBLIC_BASE_URL`，讓管理員在新增遠端 MCP 伺服器時能完成瀏覽器 OAuth。 |
| [本機 MCP 伺服器](/self-hosting/mcp-servers/setup-local-mcp/) | 在 `localhost` 或私人網路上運行 HTTP/SSE MCP 伺服器，並在 Discord 中註冊。 |
| [slop-guard](/self-hosting/mcp-servers/setup-slop-guard/) | 透過 Streamable HTTP MCP 運行容器化的 `slop-guard` 文章檢查器，用於回覆審查的規則檢查。 |

要在 Discord 中新增、檢視或移除 MCP 伺服器，請參閱 [MCP 伺服器](/features/capabilities/tools-and-extensions/mcp-servers/)。
