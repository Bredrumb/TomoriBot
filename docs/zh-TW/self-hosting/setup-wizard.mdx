`bun run setup`是推薦的本機Bun自架路徑。該指令會在載入精靈之前先從`bun.lock`安裝相依套件，包含在全新複製的環境中。精靈會建立你的`.env`、產生`CRYPTO_SECRET`、詢問你的Discord bot權杖、詢問是否[允許私人網路](#private-networks)，並設定PostgreSQL。重複執行也很安全；既有的`.env`值會保留，除非你選擇重新設定它們。

## 事前準備

開始之前，請確認你已準備好：

- **Discord bot權杖**：已啟用`GuildMembers`、`MessageContent`與`GuildPresences`特權意圖。
- **Bun**：用來執行bot與精靈本身。
- **已安裝PostgreSQL**，或是**[Docker](https://www.docker.com/)**（如果你想讓精靈替你執行PostgreSQL容器）。TomoriBot會將所有資料存放在PostgreSQL中，並在首次啟動時自動初始化其結構描述、種子資料、遷移、`pgcrypto`與RAG結構描述。
- **Node.js v20+（選用）**：如果你打算使用透過`npx`啟動的MCP伺服器。

## 執行精靈

使用以下指令執行設定精靈：

```bash
bun run setup
```

執行指令後，你會從兩條路徑中選擇一條：

| 路徑 | 何時使用 | 功能說明 |
|---|---|---|
| 完整安裝 | 你想要推薦的設定加上輕量的額外項目。 | 先執行基礎安裝，接著嘗試底下的額外項目。 |
| 基礎安裝 | 你只需要最低限度可運作的bot。 | 建立與設定`.env`、Discord權杖、PostgreSQL與相依套件。 |

### 私人網路
{/* anchor: private-networks */}

精靈會詢問TomoriBot是否可以存取`localhost`與你的區域網路，並將答案儲存為`.env`中的`ALLOW_PRIVATE_NETWORK`。在非生產環境中，未設定此項目時TomoriBot將無法啟動，因此手動設定時也需要加上這一行。任何能新增自訂端點或MCP伺服器的成員，都能存取你在這裡允許的對象，請依使用bot的對象來選擇：

| 值 | 適用時機 |
|---|---|
| `true` | 只有你或受信任的Discord社群使用這個bot。位於`localhost`或區域網路上的本機模型與MCP伺服器皆可使用，包含透過純HTTP連線。 |
| `host:port`清單，例如`localhost:5001,localhost:8188` | 你與並非完全信任的成員共用本機伺服器（例如KoboldCPP或ComfyUI）。只有列出的伺服器能正常運作，因此對方的端點無法存取你網路上的其他服務。 |
| `false` | 有不受信任的成員使用bot，且你沒有共用任何本機伺服器。 |

公開HTTPS端點（例如託管的OpenAI相容API）在任何設定值下都能運作。若模型位於另一台電腦上，請使用[經授權的遠端連線](/self-hosting/local-endpoints/proxies-and-remote-access/cloudflare-tunnel/)。通道本身僅提供連線能力，還需要另外設定存取控制。無論`ALLOW_PRIVATE_NETWORK`為何，生產環境一律拒絕私人端點。

清單會依照端點註冊時的位址進行完全比對，因此`localhost:5001`不涵蓋`127.0.0.1:5001`；請列出所有會用到的寫法。列出的伺服器依然對所有成員開放其任何路徑，因此請替該伺服器自身的管理功能加上密碼保護（例如KoboldCPP使用`--adminpassword`）。

Tailscale位址與`*.ts.net`名稱也視為私人位址，因此需要設為`true`或加入清單；若設為`false`，則只有Tailscale Funnel能夠運作。

無論你選擇哪個設定，成員張貼的圖片、檔案與連結預覽都絕對不會存取私人位址。`fetch_url`工具則有自己獨立的設定`FETCH_URL_ALLOW_PRIVATE_NETWORK`（預設為關閉）。

### 完整安裝的額外項目

完整安裝會先執行基礎安裝，接著嘗試安裝底下的額外項目。若有任何一項失敗，它會印出手動完成的指令或指南，並繼續進行：

| 額外項目 | 用途 |
|---|---|
| `pgvector` | 文件與RAG記憶的向量搜尋。 |
| `pg_cron` | 選用的排程冷卻與提醒資料列清理。 |
| Tokenizer資產 | 本機tokenizer資產，用於NovelAI文字生成與依模型調整的logit偏權值。 |

若要手動安裝其中任何一項，請參閱[手動設定的額外項目](/self-hosting/manual-setup/#optional-extras-the-manual-full-install)。

## 設定完成後

```bash
bun run dev                          # bot only
bun run launch --searxng --crawl4ai  # bot + local servers (see bun run launch --help)
```

當bot上線後，在Discord中執行`/setup`。它會引導你連接AI供應商或你的自訂端點。

## 更新

使用備份優先的更新指令：`bun run update`

這會執行`bun run backup`，接著執行`git pull --rebase --autostash`，再執行`bun install --frozen-lockfile`。若你從`dist/`執行請加上`--build`，若是Compose部署請加上`--docker`。完整詳細資訊請參閱[維護與備份](/self-hosting/maintenance/)頁面。
