TomoriBot 把語音視為自訂端點功能。本機引擎在 bot 之外以 HTTP 伺服器運行，並實作 `POST /synthesize`；複製引擎會收到文字加上設定好的參考音訊樣本，而支援 VoiceDesign 的引擎還能收到自然語言指示。

## 設定流程

1. 從上面的卡片挑一個引擎，並從 `servers/tts/` 設定它的包裝。
2. 在 `/providers` 中選擇 **新增自訂端點**，並使用 API 相容性 `tts-clone`。
3. 選取已儲存的端點，並用它的模型下拉選單加入它的 Speech 模型、語音來源模式與腳本標記風格。
4. 開啟 `/config` > 模型 > 切換模型，選取註冊好的 Speech 模型。

## 網路存取
<!-- anchor: network-access -->

所有 TTS 本機伺服器預設都綁定到 `127.0.0.1`，所以只有同一台機器上的 bot 能連到它們。當 TomoriBot 在 Docker 或另一台機器上執行時，請為伺服器設定 `TOMORI_TTS_HOST=0.0.0.0`，並用主機的位址註冊端點，例如 `http://host.docker.internal:8015`。

這些伺服器沒有驗證機制：任何能連到該連接埠的人都能用你的 GPU 執行合成。只在可信任的網路中綁定到回送以外的位址；若要把伺服器公開到該網路之外，請在前方放一個具備驗證的反向代理。

每個伺服器都讀取自己的連接埠變數（`CHATTERBOX_PORT`、`QWEN3TTS_PORT`、`IRODORI_TTS_PORT`、`FISH_S2_PORT`、`VOXCPM2_PORT`、`COSYVOICE3_PORT`、`MOSS_TTS_PORT`），因此可以用同一個 `.env` 同時執行多個伺服器。`bun run launch` 會把 `.env` 傳給它啟動的伺服器；手動啟動的伺服器只讀取其 shell 環境。

## 人格語音流程

對複製引擎而言，請為每個人格加入並指派一個語音樣本：

1. 準備一段乾淨、只有一位說話者且沒有背景音樂的片段。最適合的長度由各引擎自行說明，依模型不同落在 3 到 30 秒之間；下方各引擎的指南會列出實際數字。
2. 開啟 `/config`，在模型 > TTS 參數與語音 底下上傳該樣本。任何音訊格式都接受；TomoriBot 會將它轉成單聲道 WAV，上限 130 秒。
3. 在引擎能因此受益時提供對應的逐字稿。Fish S2 Pro 會把儲存的參考逐字稿轉送進複製請求，而 VoxCPM2 會用它做更高保真度的 Ultimate Cloning。
4. 開啟 `/config`，在人格 > 語音 底下選擇人格與語音樣本。

130 秒的上傳上限是 TomoriBot 的規定，不是任何引擎的。片段送出時，每個引擎會套用自己的參考音訊上限，而這些上限差異很大，適合某個引擎的片段可能被另一個引擎拒絕，或只被部分採用。上傳較長的片段之前，請先查看該引擎的指南。

上傳大小上限與長度上限彼此獨立，而且會先檢查大小。未壓縮的 WAV 以立體聲 44.1 kHz 計算，每分鐘約需 10 MB，因此從 DAW 匯出的 130 秒片段可能約 22 MB，會因為太大而被拒絕，而同一段片段改用壓縮格式匯出就能輕鬆過關。`SPEECH_SAMPLE_MAX_MB` 可以調高這個大小上限（預設為 10 MB）。對於較長的參考片段，請匯出成 FLAC、MP3 或 OGG，而不是 WAV：TomoriBot 會先把任何接受的格式轉成 22.05 kHz 的單聲道 WAV 再儲存，所以壓縮後上傳在品質上沒有任何損失。

對 Qwen3-TTS、MOSS-VoiceGenerator、IrodoriTTS 或 VoxCPM2 VoiceDesign 而言，請跳過音訊樣本，改用 `/config` 中的人格 > 語音 為該人格儲存一段自然語言的語音描述。CosyVoice 3 使用帶參考樣本的複製模式，並透過 `voice_instructions` 接受單次的語氣指示。

使用 ElevenLabs 的人應該在 `/providers` 中選擇 **新增供應商** 與 **ElevenLabs**，它會同時註冊語音與轉錄端點。

TomoriBot 會在合成之前，從生成的語音腳本中移除 Discord 自訂表情符號語法，例如 `:pepega:` 或 `<:pepega:123456789012345678>`。Unicode 表情符號同樣會被移除，除非語音端點使用表情符號標記，那是為 IrodoriTTS 設計的。當某個端點的腳本標記風格設為 **方括號標籤** 時，例如 Chatterbox Turbo 與 Fish S2 Pro，方括號標籤會被保留。

VoxCPM2 使用 **純文字** 腳本標記風格。它的語音設計與說話風格控制會透過 TomoriBot 的 `instruct` 欄位傳遞，而 VoxCPM2 的包裝會將它們轉成該模型原生的括號自然語言控制語法。

CosyVoice 3 同樣使用 **純文字** 腳本標記風格。它將有逐字稿的參考對應到零樣本複製、沒有逐字稿的參考對應到跨語言複製，並將 `voice_instructions` 對應到它的指示條件路徑。行內的方括號標籤會被移除，因為 CosyVoice 的指示適用於整段語句。
