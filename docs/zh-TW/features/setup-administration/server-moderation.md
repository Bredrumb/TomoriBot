TomoriBot 給伺服器管理員控制她在你伺服器裡的行為：誰可以使用她、在哪裡使用，以及她花費多少，這些都透過 `/config` 面板與相關指令。大多數需要 **管理伺服器** 權限。這一頁涵蓋重點；每個指令都收錄在[指令參考](/zh-TW/features/command-reference/)。

## 成本控制：額度

生成要花錢（你的錢，或你成員的錢）。額度會限制每位使用者與整個伺服器的用量：

- `/moderation` → **額度**：設定文字、圖片與影片生成的每日個人上限，以及會重置的伺服器共用額度池。
- `/quota reset`：手動重置某位使用者或伺服器的額度池。

把個人上限設為 `0` 表示無上限。伺服器共用額度池會依可設定的天數間隔重置。

## 使用者 BYOK（自備金鑰）

`/moderation` 的**成員存取**以兩種狀態呈現這個選項。**允許使用伺服器模型**是預設值；**必須使用個人供應商**要求每位成員為自己的觸發自備個人供應商，伺服器不為使用者發起的訊息付任何費用。伺服器發起的觸發仍然使用伺服器的供應商。這是最強的成本控制：它把 API 支出完全轉移到成員身上。成員在[個人化 → 你自己的供應商](/zh-TW/features/knowledge/personalization/#你自己的供應商)底下設定自己的供應商。

你也可以在 `/setup` 時選擇 **使用者 BYOK**，讓伺服器完全**沒有**伺服器端文字供應商。這個選項只在伺服器提供，不在私訊提供，而且它會在完成供應商步驟前要求確認，因為工作區之後就沒有可退回的供應商。

## 存取控制：白名單

- `/moderation` → **白名單** → **頻道**：選擇可觸發的頻道與選用的冷卻覆寫。
- `/moderation` → **白名單** → **人格**：限制某個人格可以在哪些頻道觸發。
- `/moderation` → **白名單** → **身分組**：把觸發限制在特定的身分組。
- `/config` > 行為 > 觸發行為：設定回覆之間的整體冷卻。

白名單頻道會沿用整體冷卻，除非你設定了頻道專屬的覆寫。

## 學習與隱私控制

- `/server memberpermissions`：控制誰可以教她事情。
- `/server blacklist`：阻止她從特定使用者學習，或使用關於他們的記憶。
- `/config` > 頻道 > 頻道規則：標記短期記憶被隔離、且思考紀錄被抑制的頻道。

## 透明度：思考紀錄

`/server thought-logs` 設定一個頻道，用來發布她的內部推理與成功的工具呼叫，這對於稽核她正在做什麼很有用（包括在[明確工具模式](/zh-TW/features/capabilities/tools-and-extensions/#明確工具模式)下是哪個觸發詞讓某個工具出現）。

## 歡迎訊息

`/config` > 頻道 > 紀錄與歡迎 會為新成員在選定的頻道設定自動問候。預設情況下，Tomori 會等一分鐘再問候他們，讓伺服器的加入流程先完成。執行個體營運者可以用 `WELCOME_DELAY_MS` 調整這段緩衝時間。用同一頁的 **清除歡迎訊息** 按鈕即可停止問候。

## 表情

`/expressions initialize` 會註冊你伺服器的自訂表情符號與貼圖，讓她能準確使用它們，建議在設定完成後立刻執行。關於她會用它們做什麼（自然地使用 `:emoji:`、貼圖、回應），請看[表情符號與回應](/zh-TW/features/chatting-personality/chatting-and-triggers/#表情符號與回應)。
