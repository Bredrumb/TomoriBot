TomoriBot透過`/moderation`和`/config`為伺服器管理者提供對使用、成本、權限和通道的細微控制。大多數這些控制項都需要`管理伺服器`權限。完整的命令清單請參考[指令參考](/features/command-reference/)。

## 成本控制：額度
<!-- anchor: cost-control-quotas -->

產生需要花錢，無論是從你的供應商帳戶還是由你的會員支付。每個使用者和伺服器範圍內的配額上限使用量：

- **設定限制**：在`/moderation` > `額度`中，設定每日每個使用者限制和用於文字、影像和影片產生的伺服器範圍重設池。將每個使用者限制設為`0`表示無限制。
- **手動重置**：執行`/quota reset user`清除成員的日常使用量，或執行`/quota reset global`重置整個伺服器的池。

伺服器範圍的池會依照可設定的時間間隔（以天為單位）自動重設。

計算方式如下：

- **文字**計算的是回覆次數，而非費用。bot 每回覆一則訊息就會消耗一個單位，不論回覆過程執行了幾個工具步驟，也不論是否沒有傳送文字，或是在模型開始回答後被 `/kill` 中斷。若模型的請求直接失敗，或在模型開始回答前就被停止，則會退還該單位。成員建立的排程任務每次執行時，都會消耗該成員的一個單位。
- **圖片與影片**在供應商接受請求後就會消耗一個單位，即使結果遭到中止或因檔案過大而無法發布也一樣，因為供應商仍會對此計費。

## 使用者BYOK（自備金鑰）
<!-- anchor: user-byok-bring-your-own-key -->

在`/moderation` > `成員存取`中，你可以控製成員是否可以使用伺服器資助的AI：

- **允許的伺服器模型**（預設）：成員使用伺服器配置的供應商。
- **需要個人供應商**：成員必須透過 `/personal providers` 設定自己的 API 金鑰。伺服器不為成員發起的訊息或成員的排程任務支付任何費用。伺服器發起的操作（例如自動問候）仍會使用伺服器供應商。

會員在[個人化](/features/knowledge/personalization/#your-own-providers)下配置他們的個人供應商。

你也可以透過在`/setup`期間選擇`使用者BYOK`來引導沒有伺服器端文字供應商的伺服器。

## 存取控制：白名單

使用`/moderation` > `白名單`來限制TomoriBot回應的位置和方式：

- **頻道**：選擇哪些頻道允許機器人回應並設定特定於頻道的冷卻時間覆蓋。除非設定了覆蓋，否則通道會繼承全域冷卻時間。
- **人格**：限制特定人格可以觸發的管道。
- **角色**：將機器人互動限制為具有特定Discord角色的成員。

在`/config` > `行為` > 觸發器行為下配置伺服器範圍的全域回應冷卻時間。

## 學習與隱私控制

- **成員權限**：在 `/moderation` > `成員存取` 中，按一下 `編輯權限` 可以控制沒有 `管理伺服器` 權限的成員是否可以管理伺服器記憶、檢視提示詞快照或匯出人格。伺服器記憶教導預設為停用，啟用時可讓成員查看自己的記憶、新增記憶，並編輯或移除自己的記憶。停用時，只有具備 `管理伺服器` 權限的成員才能查看或管理伺服器記憶。查看與管理文件與世界書需要 `管理伺服器` 權限。
- **人格匯出**：對沒有 `管理伺服器` 權限的成員預設為停用。在 `/moderation` > `成員存取` > `編輯權限` 中啟用 `人格匯出`，即可讓成員使用所有 `/persona export` 格式。這包含附帶立繪、角色參考以及選用指定語音音訊與逐字稿的組合包。成功的匯出會一律公開發佈在頻道中。沒有權限的成員會收到私人回覆，指示他們聯絡伺服器管理員。無論這項設定為何，管理員都能匯出人格。
- **使用者黑名單**：在`/moderation` > `使用者黑名單`中，選擇TomoriBot完全忽略的成員。列入黑名單的成員無法觸發她或運行命令，並且他們的訊息永遠不會到達提示上下文。你也可以設定特定於人格的成員區塊。
- **頻道規則**：在 `/config` > `頻道` > `頻道規則` 中，將公開文字頻道標記為私人，或新增跨頻道工具黑名單。受限制的 Discord 頻道會自動判定為私人。私人頻道不產生思考紀錄，也不接收傳入的跨頻道工具（包含來自其他頻道的查看、建立討論串與排程任務）。除非 `私人頻道 STM 分享` 設為 `允許`，否則其 STM 無法離開，但仍能回想來自公開頻道的 STM。你依然可以要求 bot 在私人頻道內運作或向外指派工作；向外指派的任務可以包含你對話中的資訊。

在伺服器中使用 `/config` 需要 `管理伺服器` 權限，包含檢視人格屬性、範例對話、立繪與短期記憶。人格屬性與範例對話只能由伺服器管理員編輯。私訊擁有者仍可存取自己的工作區。匯出權限僅授予 `/persona export` 的使用權限，不會授予 `/config` 或其中的 `匯出立繪` 按鈕權限。完整提示詞下載則使用獨立的 `提示詞快照` 權限。

自動隱私判定會檢查身分組權限：`@everyone` 必須能檢視該頻道，且任何身分組都不得有明確拒絕的 `檢視頻道` 權限。個別成員的權限覆寫不會影響此分類。因此，設有驗證身分組或拒絕檢視限制身分組的伺服器，即使一般成員能讀取，頻道也可能被標記為私人。面板會區分自動判定與手動選擇。移除手動選擇無法覆寫 Discord 的限制。

## 透明度：思考紀錄

在 `/config` > `頻道` > `紀錄與歡迎` 中，按一下 `設定紀錄頻道` 指定 TomoriBot 發布內部推理、備援通知與成功的工具呼叫的頻道。這對於審核她正在執行的動作很有用，包括哪個觸發詞在[明確工具模式](/features/capabilities/tools-and-extensions/deliberate-tool-mode/)下揭示了工具。

此紀錄使用與 STM 相同的身分組隱私判定。私人頻道與其討論串中的活動不會進入紀錄中。紀錄頻道必須位於同一個伺服器。

:::tip
紀錄頻道可以只對你的管理團隊開放，同時接收來自對所有身分組開放之頻道的活動。
:::

## 歡迎訊息

在`/config` > `頻道` > 日誌和歡迎中，為所選頻道中的新成員設定自動問候語。TomoriBot等待新成員完成Discord的規則篩選和加入後才發送問候語。如果會員在完成篩選之前離開，則不會發送問候語。點擊同一頁面上的`清除歡迎訊息`以停用問候語。

## 表情

運行`/expressions initialize`來索引伺服器的自訂表情符號和貼圖，以便人格可以在對話中準確地使用它們。有關人格如何使用表情符號、貼圖和反應，請參閱[表情與反應](/features/chatting-personality/chatting-and-triggers/#expressions--reactions)。
