TomoriBot 把僅限成人的 `/nsfw` 指令分類放在 Discord 內建的年齡門檻後方，在你選擇加入之前都是隱藏的。這一頁說明如何存取它，以及它在哪裡可用。

## 啟用年齡限制指令

1. 在 Discord 中開啟 **使用者設定 → 隱私與安全**。
2. 開啟 **允許應用程式存取年齡限制指令**。你必須年滿 18 歲。
3. 年齡限制指令只會在標示為 **NSFW** 的頻道中執行（在頻道上按右鍵 → **編輯頻道 → 切換 NSFW**；只有伺服器管理員可以將頻道標示為 NSFW）。

如果某個指令受到限制，而頻道沒有標示為 NSFW，它就單純不會出現。

## 什麼受到限制

- **NSFW 內容設定**：`/nsfw jailbreaks` 會切換針對過度嚴格的*供應商端*內容過濾器的繞道做法（TomoriBot 本身不加入任何自己的安全護欄）。請看[行為調整](/zh-TW/features/chatting-personality/behavior-tweaking/#無審查輸出)。

圖片與影片生成由各自設定的供應商與伺服器的功能設定分別控制；它們不受 `/nsfw` 指令分類的限制。

年齡限制內容僅限成人使用者，請負責任地使用，並遵守 Discord 的[社群守則](https://discord.com/guidelines)。在 `/help` 中選擇 **行為**，然後選 **年齡限制指令**，就能在 Discord 裡看到同樣的逐步說明。
