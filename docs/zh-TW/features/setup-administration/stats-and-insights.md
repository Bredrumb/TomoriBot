TomoriBot 會追蹤使用量，讓你看到誰跟誰說話、哪些人格與模型被使用，以及哪些工具被觸發，然後把它變成可分享的資訊圖。

## 文字儀表板

有三個指令會開啟互動式的分頁儀表板（總覽、人格、模型與費用、工具與指令、表情、人物、排行榜）：

文字分頁是由呼叫者控制的持久公開儀表板。它們會一直保持可用，直到訊息被移除，而且其他使用者無法操作這些控制項。

- `/stats personal`：你自己的使用量。
- `/stats persona`：某個人格在這個伺服器的使用量。
- `/stats server`：整個伺服器的使用量。

大多數都支援**時間範圍**視窗，而個人統計可以限定在這個伺服器，或跨所有伺服器。

:::note
**Token 數量**在供應商有提供時，採用供應商自己回報的用量（只有完全不回報的供應商才會使用以字元數為基礎的估算）。**費用**會依模型目錄的定價計算這些 token，所以可能與你的實際帳單不同（提示詞快取、折扣、免費方案額度等等）。
:::

## 可分享的資訊圖卡

`/stats generate` 會渲染一張精緻的圖片卡，讓你直接丟進聊天：

- **個人回顧**：你的個人活動，Spotify Wrapped 風格。
- **人格契合度**：某個人格在這個伺服器的統計。
- **伺服器排行榜**：整個伺服器的排名。

完全隱私的使用者（`/personal config`）無法生成個人卡。

關於卡片如何組成與渲染，請看[統計資訊圖子系統](/en/architecture/subsystems/stats-infographic/)的架構參考。
