對話錄製是一項需主動啟用的功能，僅供你個人使用，用來儲存你在伺服器中發送的訊息及其周圍的節錄。結構化的 Discord 身分會在儲存前替換為預留位置（自訂文字與外部連結仍可能識別出個人身分）。

**預設情況下，TomoriBot 不會儲存你的訊息；錄製功能為每位使用者獨立選用，僅供個人使用，且只有在你確認 `/record` 指令後才會開始。TomoriBot 不會自動建構人格、向 AI 供應商發起呼叫，也不會將這些節錄用於任何訓練流程。**

## 用途

- 保留你自己的伺服器訊息與周圍脈絡的個人存檔。
- 透過時間戳記、訊息順序與回覆連結，回顧過往的討論。
- 檢視自己的寫作風格，以便離線草擬人格筆記或提示詞。
- 匯出結構化的 Markdown 或 JSON 對話逐字稿，供個人離線使用。

## 開始與停止錄製

- **`/record start`**：選擇持續時間，以及僅儲存自己的訊息或包含周圍訊息，然後確認。除非你打算手動停止，否則請避免選擇 `直到手動停止（不建議）`。
- **進行中的工作階段**：每個伺服器只能有一個進行中的錄製。在錄製進行中執行 `/record start` 會開啟其設定：脈絡變更僅套用於新節錄；變更持續時間會從現在起設定新的結束時間，選擇相同持續時間則保留目前的結束時間。
- **`/record stop`**：停止收集並保留已儲存的節錄。
- **`/record data`**：開啟你目前伺服器的錄製內容與設定。
- **範圍**：無法在私訊中使用。伺服器管理員無法查看、匯出或刪除你的錄製內容。

## 儲存的內容

- **觸發條件**：啟用後，你發送的每一則真實訊息都可以儲存以該訊息結尾的節錄（即使 Tomori 沒有回覆也是如此）。模仿身分發送的訊息不會觸發錄製。
- **脈絡**：同一個頻道或討論串中，來自近期限定範圍內的最多 10 則符合條件的較早訊息（其時間可能早於啟用時間）。
- **模式**：`只包含我的訊息` 僅儲存你的訊息。`包含周圍的訊息` 還可儲存其他成員、bot 與網路鉤子的訊息，即使對方從未開始錄製。
- **符合條件的頻道**：你與 bot 都能檢視並讀取歷史紀錄的伺服器頻道與討論串，包含受限制的頻道與私人討論串。設定為完全隱私的成員會被略過。頻道隱私與跨頻道脈絡設定不會排除你的錄製。
- **間隔與重複**：節錄是帶有時間戳記、順序與回覆連結的重疊快照。同一則訊息可能會出現在多個節錄中。停機、遺漏事件或缺少權限會造成間隔（不會回溯補齊）。
- **嵌入內容**：將嵌入內容的標題、說明、欄位、作者名稱與頁尾儲存為訊息文字，並套用與一般文字相同的身分替換。
- **附件**：儲存圖片、影片、音訊與檔案的數量（未知類型計為檔案）。媒體位元組、檔案名稱、附件 URL、OCR 與生成的媒體說明均不會儲存。

### 易讀的身分預留位置

- 結構化的提及、頻道與身分組使用穩定的工作階段預留位置（`[SELF]`、`[PARTICIPANT_1]`、`[CHANNEL_1]`、`[ROLE_1]`）。
- 儲存前會不分大小寫替換已知唯一的名稱與暱稱（這可能會替換掉剛好與名稱相符的一般詞彙）。共用的名稱會略過，且不會進行全伺服器搜尋。
- 自訂 Discord 表情符號會轉為 `:name:`；Unicode 表情符號保持原樣。Discord 訊息連結會轉為通用標記；外部 URL 保持原樣。
- 替換為盡力處理：自訂文字與外部連結仍可能識別出個人身分。輸入的文字若看起來像預留位置，則會保留為字面文字。

## 匯出與刪除

- **匯出**：在 `/record data` 中選擇時間範圍與 Markdown 或 JSON 格式。相對範圍在你送出時結束；`所有時間` 包含所有已儲存的節錄。節錄依其結尾訊息的時間選取。
- **遞送**：檔案會以私人回覆送達（請在回覆過期前儲存）。檔案名稱包含 UTC 匯出時間與簡短匯出 ID；分割檔案還會包含部分編號。大型匯出會在完整節錄之間分割；若範圍或節錄超出大小限制，請縮小範圍。即使你日後失去來源頻道的存取權限，已儲存的節錄仍可匯出。
- **JSON ID**：每次匯出都會指派全新的不透明 ID（跨分割檔案的共用訊息保留相同的 ID；文字相同的訊息取得不同的 ID）。不會匯出 Discord 或資料庫儲存的 ID。
- **刪除**：使用 `刪除伺服器紀錄` 選擇時間範圍（包含 `所有時間`），然後確認。時間範圍在你送出選擇時結束；之後錄製的訊息仍會保留。刪除不會停止進行中的錄製，停止也不會刪除已儲存的紀錄。

## 隱私與保留期限

- **維運者存取權限與 AI**：bot 維運者將錄製內容儲存在其資料庫中，並可能擁有基礎架構存取權限。錄製功能不會向 AI 供應商發起呼叫，也不會啟動任何訓練或模仿工作流程。
- **配額**：跨所有伺服器共 100 MiB 的邏輯逐字稿內容（共用訊息依節錄分別計算）。額滿時，會從你在所有伺服器中最舊的完整節錄開始逐出。
- **保留期限**：自動過期功能預設為關閉，除非維運者設定了 `RECORD_RETENTION_DAYS`。該設定會依結尾訊息的時間讓整個節錄過期（包含現有的節錄）。
- **編輯與刪除**：觀察到的來源編輯會更新儲存的文字與附件數量；觀察到的刪除與後續的隱私排除會移除儲存的複本。離線或無法存取的事件無法被觀察到，已下載的檔案或備份則不受影響。詳見[隱私權政策](/legal/privacy-policy/)與[錄製維護](/self-hosting/maintenance/#conversation-recording-storage)。
