[MCP](https://modelcontextprotocol.io/)（Model Context Protocol）伺服器能讓你自行註冊外部工具來擴充她的能力。

### 新增線上 MCP

使用支援 MCP Streamable HTTP 或 SSE 的供應商直接 HTTPS 端點：

在 `/config` > `外掛` > `MCP 伺服器` 底下新增該端點與任何所需的驗證資訊。若是要用於回覆草稿審查的規則檢查器，請選擇 `文章檢查器`；其工具不會在聊天過程中被呼叫。

驗證權杖在靜態儲存時會經過加密。停用用於搜尋或 URL 讀取的伺服器會恢復內建工具。已儲存的工具清單反映的是上一次成功探索的結果，不保證該伺服器目前仍可連線。

工具回應上限為 8 MiB，包含 SSE 連線的整個串流。若某個工具超出此上限，請向供應商查詢分頁或較小的回應格式。

### 新增需要登入的 MCP

有些服務（例如 Linear 與 Notion）會要求你登入帳號，而不是直接給你一組權杖。新增該 MCP 時請將 `驗證權杖` 留空。當伺服器要求登入時，面板會顯示 `登入` 按鈕：

1. 選擇 `登入`，並在 10 分鐘內登入該服務。
2. 確認頁面會列出你的 Discord 伺服器與該 MCP 的位址。只有在兩者皆正確且這次登入是你親自發起時，才選擇 `連線`。
3. MCP 新增完成後，Discord 中的面板會自動更新。

每位使用該 MCP 工具的成員都會以登入帳號的身分執行操作，因此請使用其資料可讓整個伺服器看到的帳號。

當登入過期或服務要求更多權限時，該 MCP 的工具會暫停，其列位會顯示 `重新連線`。選擇它並再次登入即可；該 MCP 會保留原本的名稱、類型與欄位位置。

登入功能只在伺服器中新增 MCP 時有效，無法在私訊中使用。在自架的 bot 上，主機需先完成設定；請參閱 [MCP 登入設定](/self-hosting/mcp-servers/mcp-sign-in/)。

### 本機 MCP 伺服器

只有自架執行個體支援本機 MCP 伺服器，因為公開託管的 bot 需要 HTTPS 並封鎖本機與私人位址。若你運行自己的執行個體，請參閱[設定：本機 MCP 伺服器](/self-hosting/mcp-servers/setup-local-mcp/)。

:::danger[只新增你信任的 MCP 伺服器]
惡意的 MCP 伺服器可能會透過隱藏指令對她進行提示詞注入、外洩使用者傳給工具的資料，或傳回有害或錯誤的結果讓她轉達給你的伺服器。請像對待瀏覽器擴充功能一樣看待 MCP 伺服器：如有疑慮，請勿新增。新增前務必先檢視 MCP 所描述的工具。
:::
