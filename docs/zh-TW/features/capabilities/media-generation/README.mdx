TomoriBot 可以直接在聊天裡創作媒體：**圖片、短片與語音訊息**。用平常的話請她做（「畫給我一張……」、「把那段用語音訊息傳給我」），或使用 `/generate` 系列指令。有哪些功能可用，取決於你設定的供應商，請看[供應商與模型](/zh-TW/features/setup-administration/providers-and-models/)。

    description="Discord 原生語音訊息（文字轉語音）與音訊轉錄（語音轉文字）。" />
</CardGrid>

:::note
不是每個供應商都支援每項功能。本機生成（ComfyUI、本機語音伺服器）要在自架執行個體上才能使用，請看[自架](/zh-TW/self-hosting/)。
:::
