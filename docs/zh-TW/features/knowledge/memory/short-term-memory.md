TomoriBot 會讀取使用中頻道的近期訊息。短期記憶（STM）藉由保留暫時的運作脈絡來擴展這一點：

- **頻道脈絡：** 強化目前頻道中正在進行的話題或情境。
- **跨頻道脈絡：** 回想來自其他頻道的近期對話，若啟用了跨伺服器回想，也能回想跨伺服器的對話。

她只記得自己參與過的對話。她只在回覆時更新頻道的摘要，其他時候都不會，因此沒人跟她說話的熱鬧頻道不會留下任何記憶。每個頻道的短期記憶預設在 24 小時後過期。如果你在 `/personal config` 中選擇退出，你的訊息就會從短期記憶中排除。

最新的短期記憶以及包含其他頻道內容的記憶會緊鄰最新四個發言回合上方放置。在預設設定下，來自此頻道的較舊記憶會保留在對話上方。如果設定了較淺的深度，則可讓內容更靠近最新訊息。完整的版面配置請參閱[深入提示詞](/features/knowledge/inside-the-prompt/)。

## 跨頻道範例

- **公開頻道：** 你在 `#music` 與 TomoriBot 討論專輯推薦。幾分鐘後在 `#general`，你問她剛才推薦了哪張專輯。因為她在 `#music` 中回覆過，所以她在 `#general` 能回想起該脈絡。
- **私人頻道：** 如果該對話發生在私人頻道中，她不會在 `#general` 回想起它。除非管理員在 `/config` > `權限` 下啟用「STM 隱私權旁路」，否則來自私人頻道的摘要會保持隔離。

## 管理短期記憶
<!-- anchor: managing-short-term-memory -->

你可以在 `/config` > `人格` > `記憶` 下檢視或更正目前頻道的摘要。
伺服器管理員可以在 `/config` > `行為` > `進階記憶` 下調整參數或停用短期記憶，並在 `/memories` > `短期` 下檢視或清除使用中的頻道摘要。
`/refresh` 會清除目前頻道的記憶。
