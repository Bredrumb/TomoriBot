世界書是用於角色扮演世界、角色以及重複出現的故事細節的進階記憶。日常對話請使用「記憶」。當世界書條目的關鍵詞出現在最近的訊息中時，它們會回想出你所寫下的細節。

在 `/memories` > `世界書` 中管理世界書。每位成員都可以查看目前範圍內的條目；只有具備 `管理伺服器` 權限的成員才能新增、編輯、匯入、匯出或刪除條目。

## 全伺服器與人格世界書

世界書有兩個範圍：

- **全伺服器**世界書適用於伺服器中的每個人格。請先選取一本世界書，然後在其中選取條目。
- **人格**條目屬於某個人格同脈。在人格被移除並重新匯入後，這些條目仍然繼續生效。

使用頁面頂部的 `全伺服器` 與 `人格` 按鈕來切換範圍。人格清單會將共用同脈的人格歸為一組，因為它們共用同一本書。頻道限制與全伺服器/人格範圍是兩項獨立的控制：範圍決定了誰擁有該條目，而頻道則決定了它可以在何處出現。

## 編寫條目

為每個條目設定標題、關鍵詞以及最多 4,000 個字元的內容。關鍵詞是以逗號分隔的字詞或片語。相符比對時會忽略大小寫以及全形/半形差異。

對於無需關鍵詞相符即可生效的背景事實，關鍵詞可保持留空。再次新增關鍵詞即可還原關鍵詞比對。新條目預設使用人格之後的插入位置；匯入的條目保持其原本的位置。SillyTavern 預設集的世界設定插槽控制人格之前與人格之後兩組內容的出現位置。

## 條目何時生效

已啟用的條目必須關鍵詞相符才能生效，除非其關鍵詞留空。範圍與頻道限制對沒有關鍵詞的條目仍然適用。

`生效規則` 控制次要關鍵詞、搜尋最近訊息的數量（1 到 100 則）、觸發機率以及插入順序。次要關鍵詞可以要求符合任一次要關鍵詞（OR）、符合全部次要關鍵詞（AND）、無次要關鍵詞（NOR）或非全部次要關鍵詞（NAND）。插入順序數值越小，出現得越靠前。

觸發機率從 0% 到 100%。設為 0 則不生效，包含沒有關鍵詞的條目。匯入檔案中缺失或為 null 的機率預設為 100%；明確設定的 0% 保持為 0%。`已關閉` 的條目會保持儲存狀態，不會進入提示詞。

關鍵詞相符為精確字面比對。類似 `/a+/` 這類正規表示式格式的關鍵詞會按原文保留，不會作為正規表示式執行。

## 進入提示詞的內容

生效的條目會按插入順序，在每個插入位置作為一個 `World Info` 區塊傳送。兩個區塊共用 8,000 個字元的上限；超出上限的條目會被略過，以讓後續條目仍能容納。

內容中可以使用 `{{user}}`、`{{char}}` 與 `{{bot}}`。TomoriBot 會將它們替換為目前的實際名稱。其他 `{{...}}` 巨集與條件式區塊保持原樣。

## 頻道限制

全伺服器頻道限制屬於合集層級，並套用至其中的所有條目。可以在合集狀態按鈕旁的 `頻道` 處進行設定。人格世界書則在每個條目上保留頻道限制。頻道留空表示允許在所有頻道中使用；討論串跟隨其父頻道。

合集的 `已啟用` / `已關閉` 按鈕控制整本世界書。將其關閉會使所有條目不在對話中生效，而不會改變每個條目自身的啟用狀態。重新啟用合集會保留各個條目原有的啟用或關閉狀態。

由較舊的帶關鍵詞標籤伺服器記憶轉換而來的人格世界設定，可能仍帶有尚未解析的 `#channel` 名稱。在管理員儲存頻道選取之前，TomoriBot 會將該條目視為在所有頻道中均有效，並在世界書頁面上對其進行標記。

## 匯入世界書

在全伺服器範圍下，在合集選取器中選取 `+ 匯入世界書`，即可根據上傳的檔案建立一本世界書。其名稱預設使用檔案內的世界書名稱，其次使用檔案名稱；你也可以在匯入對話方塊中輸入名稱。已存在的名稱會被拒絕，因此匯入新書不會覆寫既有世界書。在已選世界書的條目選取器中，使用 `+ 匯入條目` 可以附加或取代其中的條目。

對於人格範圍，由於該人格擁有單獨一本書，`+ 匯入世界書` 保留在條目選取器中。兩種匯入均接受 SillyTavern 世界設定 JSON、角色書 JSON 以及 PNG、CHARX 或 JSON 格式的角色卡。在此處上傳角色卡只會匯入其中內嵌的角色書。沒有角色書的卡片不會變更所選的世界書。

預設行為是附加：已存在的條目會被略過，並新增新條目。勾選 `取代此世界書` 可僅取代所選的世界書。其他全伺服器世界書保持不變。每個人格最多可容納 250 條條目，全伺服器世界書共享獨立的 250 條條目上限；超出該上限的匯入會被整體拒絕，不會出現僅匯入一部分的情況。JSON 檔案限制為 2 MB；PNG 與 CHARX 卡片使用上傳對話方塊中顯示的主機家人格匯入限制。

收據會顯示新增了多少條條目以及略過了多少條。略過的計數包含重複項以及轉換器無法使用的條目（例如沒有內容的條目）。沒有對應目標的設定（例如群組、遞迴、黏性計時器、冷卻時間與觸發器）會被統計並捨棄。第 2 到第 7 個世界設定位置會放在人格之前。正規表示式關鍵詞保持原樣不啟用。匯入收據會標明不支援的關鍵詞與設定。

卡片中的角色書會由 `/persona import` 作為該人格的世界書匯入；請參閱[SillyTavern 支援](/features/integrations/sillytavern-support/)。

## 匯出世界書

在條目選取器中選取 `+ 匯出世界書`，會將選取中的全伺服器世界書或人格世界書下載為 SillyTavern 世界設定 JSON。可以透過相同的世界書上傳重新匯入它。條目的生效設定與個別條目的啟用狀態會隨檔案一起匯出；頻道限制、待解析的頻道名稱以及合集狀態則不會包含在內。

如果需要保留這些限制與合集設定的伺服器備份，請使用 `/export memories` 並選取 `所有人格`。`主要人格` 與 `選定的人格` 僅匯出記憶，並在匯入時保持目標世界設定不變。
